# Portafolio de Karen Cruz

Sitio estático de HTML, CSS y JavaScript. Diseño Universo creativo + Bento neón.

## Publicar en Render

Si subes **esta carpeta como raíz de un repositorio nuevo**:

- Tipo: Static Site.
- Build Command: `echo "Portfolio listo"`.
- Publish Directory: `.`.
- El archivo `render.yaml` también permite crear el sitio como Blueprint.

Si guardas esta carpeta dentro de un repositorio existente, configura Root Directory con el nombre de la carpeta y Publish Directory con `.`.

## Actualizar contenido

- `content.js`: proyectos, aportes, tecnologías y enlaces.
- `index.html`: presentación, formación y correo público.
- `styles.css`: composición, colores y adaptación móvil.
- `app.js`: credencial, estrellas, pestañas y detalles de proyectos.
- `assets/karen.jpg`: fotografía elegida y optimizada.

La investigación se presenta con una reseña de colaboración y sin enlaces al repositorio privado. Las portadas de proyectos son ilustraciones gráficas, no capturas de las aplicaciones.

## Probar localmente

Desde esta carpeta, ejecuta `python -m http.server 8791` y abre `http://localhost:8791`.

## Contacto

El botón Escribirme abre el correo del visitante. Copiar correo usa el portapapeles cuando el navegador lo permite. No hay un formulario que simule enviar mensajes ni un backend de correo.

Los movimientos pueden pausarse desde el botón superior. Se respeta la preferencia de movimiento reducido del sistema. La credencial se puede arrastrar y el botón Ver el otro lado permite girarla sin arrastrar.

## Curriculum descargable

`assets/CV_Karen_Ximena_Cruz_Full_Stack.pdf` es la versión pública del CV. Los botones de la portada y de contacto descargan ese archivo. Para actualizarlo, reemplaza el PDF conservando el nombre.
