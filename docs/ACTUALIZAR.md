# Cómo actualizar este perfil

El README.md de la raíz aparece en el perfil público de GitHub.

## Archivos
- assets/banner.svg: presentación y animación decorativa.
- assets/focus.svg: tarjetas de frontend, backend y datos.
- assets/calendar.svg y assets/research.svg: tarjetas de proyectos.
- README.md: contenido, enlaces y detalles desplegables.

## Añadir un proyecto
1. Añade un apartado en Proyectos con nombre, problema que resuelve, tu aporte y tecnologías reales.
2. Incluye un enlace al código o demostración cuando sea público.
3. Si añades una tarjeta SVG, acompáñala con texto alternativo y una descripción legible en el README.
4. Comprueba enlaces, visualización móvil y que no haya datos personales de terceros, claves ni información interna.

## Diseño
Fondo #0e111a; panel #191b2c; violeta #b9a0ff; menta #78efd2; texto #f5f3ff.
Las animaciones SVG son decorativas y respetan prefers-reduced-motion. El README usa navegación y detalles nativos; no ejecuta JavaScript.
Los badges dependen de Shields.io; los recursos visuales principales están en este repositorio.

## Futuro portafolio
Cuando exista una URL publicada, añádela a la navegación y a Conectemos.


## Universo creativo + Bento neón
El banner actual es assets/banner-universo.gif, con órbitas y estrellas. assets/banner-universo.png es la alternativa estática para movimiento reducido. El script de generación está en scripts/generate-banner.py; usa Pillow y las fuentes Arial de Windows. El banner.svg anterior se conserva como versión previa.
